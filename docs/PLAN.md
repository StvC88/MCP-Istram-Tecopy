# Plan vigente

Alcance general: las [soluciones oficiales de ISTRAM](https://istram.net/istram/caracteristicas/soluciones/). Prioridad y cobertura: [docs/SCOPE.md](SCOPE.md).

## Base implementada

Servidor MCP stdio con el SDK oficial; lectores; copias y recuperación; cola de operaciones; trabajador Windows/IFC. El prototipo anterior y su plan han sido retirados.

## Siguiente: contexto y prueba de consulta

1. Revisar ayuda oficial instalada y guías oficiales en línea. Registrar documento, revisión y procedimiento.
2. Contrastar el curso del cuaderno indicado con sus fuentes originales. Las síntesis locales ayudan a preparar la revisión; no sustituyen las clases completas.
3. Revisar los vídeos del canal solicitado y aclarar la referencia a «Aldo». Registrar enlaces y marcas de tiempo de cada flujo utilizado.
4. Consultar la sesión activa, identificar el proyecto abierto y verificar que la consulta no cambia archivos.
5. Emitir un informe local con resultados y pendientes. Los datos del proyecto no se suben a GitHub.

## Después: operaciones nativas

Preparar un adaptador mínimo a partir de controles y procedimientos comprobados. Prioridad: identificación del proyecto, guardado, recálculo, configuración BIM, generación y exportación IFC. Usar copias y ampliar comandos por flujo verificado.

Contrastar eje, rasante y sección conjuntamente; revisar unidades, coordenadas, propiedades, clasificación y cantidades. Registrar resultados de aceptación antes de marcar un perfil como verificado.

## Revisión del fabricante

Buhodra revisará primero el contrato de herramientas, formatos y método de automatización. Una API o mecanismo admitido por el fabricante tendrá prioridad sobre la interfaz gráfica cuando esté disponible.

## Pendientes

Acceso completo a vídeos y cuaderno; identificación de la sesión/proyecto; prueba nativa; perfil certificado. El estado de CI es independiente de estos pendientes.
